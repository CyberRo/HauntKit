## 📁 Estructura

```
HauntKit/
├── tools/          # Herramientas de seguridad ofensiva
│   ├── recon/      # Reconocimiento y OSINT
│   ├── exploit/    # Explotación y post-explotación
│   ├── scanning/   # Escáneres y enumeración
│   └── utils/      # Utilidades varias
├── scripts/        # Scripts de automatización y deploy
├── app/            # Futura aplicación GUI/CLI unificada
└── docs/           # Documentación
```

## 🚀 Instalación

```bash
git clone https://github.com/CyberRo/HauntKit.git
cd HauntKit
chmod +x scripts/install.sh
./scripts/install.sh
```

## ⚡ Uso rápido

```bash
# Listar herramientas disponibles
python haunt.py --list

# Ejecutar herramienta específica
python haunt.py run recon/dominoscope

# Modo arsenal completo
python haunt.py --all
```
